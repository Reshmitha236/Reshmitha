# Supply Chain Visibility System With Optimization Analytics

## Project Overview
This project uses Microsoft Power BI to analyze supply chain operations and support data-driven decision-making.

## Project Objectives
- Build a data model for supply chain analysis.
- Develop KPIs and DAX measures.
- Analyze inventory and delivery performance.
- Evaluate supplier and transportation performance.
- Monitor warehouse efficiency and create an executive dashboard.

## Project Milestones
1. **Milestone 1:** Data Modelling & KPI Foundation
2. **Milestone 2:** Inventory & Delivery Analytics
3. **Milestone 3:** Supplier & Transportation Analytics
4. **Milestone 4:** Warehouse Analytics & Final Dashboard

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Project Deliverables
- Power BI dashboards
- Excel datasets
- Project documentation
- Dashboard screenshots

## Key Learning Outcomes
- Data cleaning and transformation
- Data modelling
- KPI development using DAX
- Interactive dashboard development
- Supply chain performance analysis
